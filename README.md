# LoL Triggerbot

Download: soon

Auto-attack trigger for League of Legends.

Fires a right-click on the enemy under the cursor with a configurable delay and zone. Useful for last-hit and trade timing.

| delay | 30–110 ms |
| zone | 2–7 px |

Windows 10/11, Riot Client, administrator. F8 toggles. Vanguard.
